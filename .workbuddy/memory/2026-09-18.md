### 最重要的技术发现（务必记住，后续所有仿真代码都依赖）
**推进方式必须改为 (b)：先 `app_utils.play()`**。
原计划的 (a) `SimulationManager.step()` 单独调用**不驱动物理** —— 时间递增、步数递增，但刚体一动不动。
这是本项目目前为止最阴的坑：不报错、指标看起来正常，只有刚体不动。
`play()` 之后两者都可用（`simulation_app.update()` 主用，`step(steps=N)` 需手动步进时用）。

**"物理静默不跑"三件套**（缺任一都会静默失效）：
1. `app_utils.play()`
2. `SimulationManager.set_default_physics_scene(path)`
3. `PhysicsScene.set_gravity(...)`（默认未 author，读出来 NaN）

### 其他实测坑（已写入 agents.md §9.1）
- step() 的 steps 是 keyword-only
- RigidPrim 返回 Warp 数组需 .numpy()
- apply_collision_apis 在 GeomPrim 不在 RigidPrim
- set_local_poses 用 translations=；set_world_poses 才用 positions=
- SimulationManager 无 play/pause/reset/stop
- stage 无 clear_stage；重建 stage 会让旧 prim 失效 → 用原地 set_world_poses + set_velocities 复位
- Cube/GroundPlane 自带 positions/sizes/scales，无需 XformPrim
- 确定性复跑必须"两遍都从同一复位态开始"（我第一版测法错了：第一遍从中途开始采样，导致误判）

**三条硬结论：**
1. **ω=0.2 的异常是"起动瞬态没脱开"**，不是物理效应。同一个 90° 窗口，warm 60→240 步：
   误差 −3.48% → −1.53%，半径极差 0.6510 → 0.0144 cm（**改善 45 倍**）。
   → **实验纪律：低速指令必须加长 warm**（ω≤0.2 需 ≥240 步 / 4 s）。
2. **残余误差有符号且随 ω 单调**：−1.53%（0.2）→ −1.79%（0.5）→ +0.86%（1.0）→ +2.22%（2.0），
   **过零在 ω≈0.7 rad/s**。低速欠转、高速转过。定性符合"后被动轮侧向刮擦的摩擦性质随速度变化"
   （低速静摩擦主导阻力大 / 高速转动摩擦阻力小），**但机制未证实**。
3. **AGV 工作区间的真实误差 ≤ 2.2%**，第一轮报的 2.58–6.76% **已作废**（被窗口污染）。

### ⚠️ 我这一轮犯了两个"过度外推"的错误，已更正
1. **把被污染的数据当结论**：第一轮就写下"90° 转向有 2.3°–6.1° 航向误差、10 m 后横向 0.4–1.1 m"，
   并据此说"S5 必须闭合回路，这是硬约束"。修正后是 ≤2°、≈0.35 m。**结论方向对但量级虚高一档。**
   → 教训：**结论写进文档前，先用控制变量实验排除测量伪影。**
2. **把有界偏差说成"累积"**：A-017 与报告都写了"每 90° 转向累积约 4.7 cm"。
   刚体定轴转动的原点位移是 `2R·sin(Δψ/2)`，**有界且周期**——转满 360° 回起点

   → 真实影响是：单次转向瞬时偏差可达 2R≈12 cm（影响碰撞裕度与观测）；R 随工况漂移 2.5–6.0 cm。
