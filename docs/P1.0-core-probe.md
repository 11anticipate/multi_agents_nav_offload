## 4. 速度扫描（零重力自由空间，0.2 m 立方体，接触距离 0.200 m）

|---|---|---|---|---|
| 1 | 0.017 | 0.200 | 0.200 | 一致 |
| 2 | 0.033 | 0.200 | 0.236 | 一致（干净接触） |
| 4 | 0.067 | 0.200 | 0.199 | 一致 |
| 8 | 0.133 | 0.133 | 0.217 | **偏差**，新 Core 重叠更深 |

- `SimulationManager.enable_ccd(True)` 对上述结果**无可观测影响**（两表完全相同）。
- **对项目的结论**：AGV 工作速度 0.5–3 m/s 内最小间距恒为 0.200 m，即干净接触、无重叠 —— 该区间内物理保真度满足 P1.0 需求，无需 CCD。

## 5. 实测坑清单

1. `SimulationManager.step()` **单独调用不驱动物理**，必须先 `app_utils.play()`；之后 `step()` 或 `simulation_app.update()` 均可。
2. 必须 `set_default_physics_scene(path)`，否则默认场景为 `None`，日志报 `Invalid default physics scene path: None`，物理静默不跑。
3. `PhysicsScene` 默认重力未 author，读出来是 `(nan, nan, nan)`，必须显式 `set_gravity`。
4. `step()` 的 `steps` 是 keyword-only，`step(100)` 报错。
5. `RigidPrim` 返回 Warp 数组，不是 numpy。
6. `apply_collision_apis` 在 `GeomPrim` 上，**不在** `RigidPrim` 上。
7. `set_local_poses` 用 `translations=`；`set_world_poses` 才用 `positions=`。
8. `SimulationManager` **没有** `play` / `pause` / `reset` / `stop`（时间线控制走 `app_utils`）。
9. `Cube` / `GroundPlane` 自带 `positions` / `sizes` / `scales`，无需再用 `XformPrim` 设位姿。
10. 重建 stage 会让旧 prim 失效（`Accessed invalid expired prim`）；复用场景应原地 `set_world_poses` + `set_velocities` 复位。

## 6. 结论

新 Core（`isaacsim.core.experimental.*`）**可独立支撑 P1.0**：T0–T5、T7、T8 全部通过，且确定性为 bit 级一致。
推进方式定为 **先 `app_utils.play()`，之后可用 `simulation_app.update()`（主）或 `SimulationManager.step(steps=N)`（需手动步进时）**。

## 7. 遗留

- S1.2 扫描数据仅作基线，8/16 m/s 处新旧 Core 存在偏差，若论文引用需注明测试条件并只声明低速区间结论。
- CCD 无效的原因未追查（可能需 PhysX scene 侧配置而非全局开关）。
- `enable_ccd`、`switch_physics_engine`（Newton 后端）未评估。
